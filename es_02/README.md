### **Code execution**

To the execute the code is is necessary to move with the terminal in the respective directory:
- `ES2.1/SOURCE`
- `ES2.2/SOURCE`
and run the command `make` and `./esercizio2.1.exe`, `./esercizio2.2.exe`. The data outputs are present for each `ES2` in the directory `DATA` and the images generated from the notebook are saved in the directories `IMAGES`.
