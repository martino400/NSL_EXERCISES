### **Code execution**

To the execute the code is is necessary to move with the terminal in the respective directory:
- `ES1.1/SOURCE`
- `ES1.2/SOURCE`
- `ES1.3/SOURCE`
and run the command `make` and `./esercizio1.1.exe`, `./esercizio1.2.exe` or `./esercizio1.3.exe`. The data outputs are present for each `ES1....` in the directory `DATA` and the images generated from the notebook are saved in the directories `IMAGES`.
