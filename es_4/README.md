In `5K` and `50K` are saved the data for the Time inversion exercise (5K and 50k correspond to the number of steps taken on the first round).
`delta_animation` is a video of the particles for exercise 2 and in `OUTPUT.2` are saved the data to plot the different energies for exercise.2

In `NSL_SIMULATOR.2/SOURCE` it is possible to find the implemented functions for exercise 2 (through input.dat it is possible to execute the runs to obtain the data in `5K` and `50K`) and in ``NSL_SIMULATOR.2/POFV` is the data found for the pofv of exercise 2.

To run the code it is necessary to write in the terminal `make` and then `./simulator.exe`
